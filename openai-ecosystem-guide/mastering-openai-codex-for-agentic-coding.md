# Mastering OpenAI Codex for Agentic Coding

<details>

<summary><strong>LEARNING OBJECTIVES</strong></summary>

* An understanding of how OpenAI Codex works as an agentic coding platform
* Hands-on experience configuring the Codex CLI and IDE extension for repository-based workflows
* The ability to write effective AGENTS.md files for project conventions, testing, and task guidance
* Familiarity with Skills, Automations, and MCP-based integrations in Codex workflows
* The ability to use Codex in GitHub-based development and review workflows
* Hands-on experience building a Flask application by delegating scoped tasks through prompts

</details>

<details>

<summary><strong>ABOUT THIS COURSE</strong></summary>

OpenAI Codex is a coding agent that can read a repository, follow project instructions, run commands, and complete software tasks in a controlled environment. It is useful for developers who want to move beyond code suggestions and use a more agentic workflow for building, testing, and reviewing software.

In this course, you’ll explore how Codex works and how to configure the CLI and IDE extension for practical use. You’ll learn how to write effective AGENTS.md files and use Skills, Automations, and MCP servers to extend Codex with reusable workflows and external tools. You’ll then apply these concepts in a project by building a Flask-based pixel art canvas application through a series of structured tasks, including application scaffolding, drawing and saving functionality, a gallery page, and PNG export.

By the end of the course, you’ll be able to set up a reliable Codex workflow, delegate multi-step development tasks with confidence, and connect Codex to external tools and services. This course also covers how to use Codex in GitHub-based workflows to build and deploy software more efficiently.

### Why choose this course?

{% stepper %}
{% step %}
### An Agent That Reads, Plans, and Executes

OpenAI Codex reads the repository, plans the implementation, writes the code, runs the tests, and reports the result. Every action runs inside a sandbox, keeping changes isolated until you review them.
{% endstep %}

{% step %}
### Teaching Codex Your Codebase with AGENTS.md

AGENTS.md is a Markdown file that Codex reads before every task. It captures test commands, project conventions, and review guidelines so you never need to repeat the same context in each prompt.
{% endstep %}

{% step %}
### Connecting Codex to the Tools You Already Use

With Model Context Protocol, Codex can reach beyond the local repository. Configure an MCP server and it can read GitHub issues, query live documentation, inspect Figma designs, or pull error logs from Sentry as part of any task.
{% endstep %}

{% step %}
### From a Blank Folder to a Shipped Application

This course includes a hands-on project: a Flask pixel art canvas app built entirely through Codex prompts. Four tasks take the app from an empty folder to a working gallery with drawing, saving, and PNG export.
{% endstep %}
{% endstepper %}
